# Dr. Krishan Singh — Industrial Relations Advisor

A modern, responsive, dark/light themed executive microsite for Dr. Krishan Singh, Industrial Relations Advisor.

## Features
- **Responsive Layout:** Optimized for Desktop, Tablet, and Mobile devices.
- **Theme Toggle:** Dynamic Dark and Light mode support.
- **Interactive UI:** Smooth scrolling, section navigation, and reveal animations.
- **Custom Sections:** Hero, About, Services, Expertise, Journey, and Contact.

## Technologies Used
- HTML5
- Vanilla CSS3
- JavaScript (ES6)
